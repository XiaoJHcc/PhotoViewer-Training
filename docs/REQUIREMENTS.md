# 需求锚点 Requirements

> 本项目"要什么、什么算成功"的唯一现行真源。每条裁定标注日期与来源；2026-07-19 之前的原始论证语境见 [../plans/dinov3-photo-ranking-plan-3-0-charter.md](../plans/dinov3-photo-ranking-plan-3-0-charter.md) §0（宪法 v1.9，已冻结为历史快照）。
> 实验结论与负知识见 [KNOWLEDGE.md](KNOWLEDGE.md)；标注资产明细见 [ANNOTATIONS.md](ANNOTATIONS.md)；当前进度见 [../STATUS.md](../STATUS.md)。

## 1. 用户与场景

- 摄影爱好者（SONY A7C2），多拍选优工作流；单次外拍约 600 张/天，同地点多角度、多焦距、多构图反复尝试，大量照片高度相似。（宪法 §0.1）
- 要替代的核心成本：人工筛选一次外拍约 **5 小时**。两类最耗神的工作：① 高度相似照片里选更好的（相对区分）；② 平平无奇里挑氛围优秀的（绝对直觉）。（宪法 §0.2）
- 整体质量随天气/光线真实波动：好天气的 1 星可能比坏天气的 3 星更好——筛选必须在局部上下文里比较，不能用一把全局标尺拍平。（宪法 §0.2）
- 产品侧只需要把人工细看的量压到 ~12.5%（约 75 张）且 3★ 以上照片 80% 以上不漏；不必精确复刻每张星级。（宪法 §0.2）

## 2. 数据的本质（一切设计约束的来源）

> 压缩版；完整表述以宪法 §0.3 为准。

- 历史约 2.5 万组照片已全部人工 0–5 星标注；星级是**段内锦标赛逐轮晋级（每轮 Top 50%）的"生存结果"**：段内相对信号强，跨段/跨场绝对信号几乎为零。（宪法 §0.3）
- **星级只有排序、无数值意义**（用户 2026-07-19 强调，宪法 v1.7）：禁止相减/平均/回归等数值运算；只可反推生成过程后按序使用。
- **两段标注机制**（用户 2026-07-19 确认，宪法 v1.6）：0–3★ 偏局部（临近滑窗选优），3–5★ 偏全局（事件内总体比选）；配对域因此不同。
- **清洁度与代表身份绑定**（用户 2026-07-19，宪法 v1.8）：相似团落败者的低星含"重复压低"成分；团顶与孤立照的原始星级干净，是绝对尺唯一合法学习源。
- **0★ 即真 0★**（用户 2026-07-19 终裁）：两个照片盘全部评过，不存在"未评"。
- 标签掺入后期潜力考量（构图/内容权重高于影调，因影调可后期修复）；雾/低对比片的星级建立在增强后视图上。（宪法 §0.3）
- 团内精细判别（连拍间构图/瞬间取舍）**本身就是美学任务**（用户 2026-07-19 强调，宪法 v1.9），只有"真无差异"才判 tie。

## 3. 目标演进（三个时期并置，当前有效层 = 第三层）

1. **原始唯一目标**（宪法 §0.6）：让模型真正理解摄影美学，对任意照片给出反映其水准的分数；单一能力、单一分数。
2. **阶段规则**（用户 2026-07-27 裁定）：现阶段不考虑任何产品化，模型准确性是唯一成功判据；最低成功限度 = 三级台阶——① 高分段任意两张谁强谁弱 → ② 相似组内选优 → ③ 团顶之间排序。
3. **三能力定义**（路线审查 2026-09-21 重述，当前有效）：
   - **局部选优**：相似组中保留一张或数张真正值得留的照片；允许多个等价最佳；
   - **全局精选**：组顶与孤立照片放在一起，能找出跨组仍出色的照片；"差组中最好"不自动等于"全局好"；
   - **减量且不漏佳作**：给定人工能看的张数（12.5% 为重点预算位），最大限度保住值得留的作品，压低重复占位；模型质量必须在这个预算口径下兑现。
   - 注：旧宪法"单一分数/单头"是**实现约束**而非用户价值本身；是否允许局部/全局双通道是开放项（见 §6），尚未裁定。

## 4. 成功判据

- **准确性目标剖面**（用户 2026-07-19 给数，草案）：0–5 星评定 exact ≥50% / 飘 1 星 ≤45% / 飘 2 星 ≤5% / 偏 3 星 0（即 ±1 内 ≥95%）；≥2 硬错误须区分"重复压低污染"样本单独分析。
- **人类线**（2026-08-31 同卷复测钉死，golden_retest 73 团、54 双决胜组）：团内冠军一致 **0.704** / 前二 **0.926**；单张盲评复测 55% exact / 45% 飘 1 / 0% 飘 ≥2。"达到人类线即判定可用"。比较时人机必须同卷同分母（2026-09-21 审查口径）。
- **召回门槛**：≥3★ 召回率 ≥80% @ 人工只看 Top 12.5%（产品阶段门槛；12.5% 是理想锦标赛值，实测占比 9.8% 不改口径，用户 2026-07-19 裁定）。
- **评估口径**：容差分层报告（exact / ≤1 / ≥2 / ≥3）；tie 区（真无差异）不强迫二选一，模型应以分数接近表达不确定；金标准考卷（113 团）**永久不入训**；最终验收须用未参与训练与调参的完整新事件（v2 时代裁定，2026-09-24）。
- **场景覆盖**：七类典型场景（同山头不同构图、长焦梯田构成、沿山脊移动前景变化、静物连拍像素级、孤立瞬间抓拍、主体 vs 背景题材化权衡、夜景抖动）——逐类明细表见宪法 §0.5。
- **商业意义**：5 小时人工 → 约半小时人机协作；不被"全自动精确打分"执念带偏。

## 5. 原则约束（长期有效）

- 评估必须**事件级切分**（泄漏 0.99 vs 藏一场 0.50 的实证差距）；同次拍摄绝不跨 split。（宪法 §0.7 + 决策 11）
- 比较只在局部可比域内发生；内容相似度是可比性主信号；禁止原始星级跨段直接组对（≥3★ 事件内全局段除外）。（宪法 §0.7/决策 2）
- 标签是带噪声的软偏好：监督带可信度权重，不做"星高必胜"硬约束；整数舍入是量化噪声——AI 不学它，也不许拿它当降低标准的借口，闸门只卡真实差异处（Δ≥2）。（宪法 §0.7 + plan-3-2 §6 校准注记）
- EXIF 拍摄参数不进打分特征（反迁移实证，LOG 2026-07-19），只作分桶元数据。
- 模型输入增强必须确定性、推理期可复现；禁破坏性抹除影调；手动修图只作参照不作输入。（宪法决策 13）
- 废片闸门是模型外的独立协同算法；训练库是"删除后的幸存者"，模型不负责废片检测。（宪法决策 14）
- 软权重、数据驱动，不堆人工硬规则。（宪法 §0.7）
