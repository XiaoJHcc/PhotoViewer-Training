## 1. 用户与场景

- 摄影爱好者（SONY A7C2），旅游外拍、走到哪拍到哪的多拍选优工作流；单次外拍约 300–600 张/天，同地点多角度、多焦距、多构图反复尝试，大量照片高度相似（拍摄习惯与数据产生的亲笔描述 → [HUMAN.md](HUMAN.md)）。
- 要替代的核心成本：人工筛选一次外拍约 **5 小时**。两类最耗神的工作：① 高度相似照片里选更好的（相对区分）；② 平平无奇里挑氛围优秀的（绝对直觉）。
- 整体质量随天气/光线真实波动：好天气的 1 星可能比坏天气的 3 星更好——筛选必须在局部上下文里比较，不能用一把全局标尺拍平。
- 产品侧只需要把人工细看的量压到 ~12.5%（约 75 张）且 3★ 以上照片 80% 以上不漏；不必精确复刻每张星级。

## 2. 数据语义裁定（用户裁定，约束一切数据使用）

> 本节只收用户裁定过的**语义规则**（怎么读数据、什么合法什么不合法）。历史标签的**生成机制（习惯）** → [HUMAN.md](HUMAN.md)（真源）+ [SUPERVISION.md](SUPERVISION.md) §0.1（执行补充）；标签的**实测性质** → [KNOWLEDGE.md](KNOWLEDGE.md) §1；原始完整表述 → 宪法 §0.3。

- **星级只有排序、无数值意义**：禁止相减/平均/回归等数值运算；只可反推生成过程（段内滑窗锦标赛 + ≥3★ 筛选后的事件内全局比对）后按序使用。
- **两段标注机制**：0–3★ 偏局部（临近滑窗选优），3–5★ 偏全局（事件内总体比选）；配对域因此不同。
- **清洁度与代表身份绑定**：相似团落败者的低星含"重复压低"成分；团顶与孤立照的原始星级干净，是绝对尺唯一合法学习源。
- **0★ 即真 0★**：所有指定的数据集内照片全部评过，不存在"未评"。
- 标签掺入后期潜力考量（构图/内容权重高于影调，因影调可后期修复）；雾/低对比片的星级建立在增强后视图上。（先验登记 → SUPERVISION §0.2 #7/#9）
- 团内精细判别（连拍间构图/瞬间取舍）**本身就是美学任务**，只有"真无差异"才判 tie。

## 3. 目标结构（2026-10-13 用户澄清后重写）

- **产品化底线目标 = ≥3★（场景代表作）的准确召回**：一整套自动选片流程跑完，人工只需复核保留集；**3★ 准确召回是"能否产品化"的判据本身**，不是众多指标中的一个。此前把它当"指标"而非"目标"，是训练长期偏离产品用途的根源（用户 2026-10-13）。
- **第一期机制（不可自造代理）**：选片单位 = **时间线上的滑动窗口局部比选 + 逐层抬举**（HUMAN：0–3★ 在时间段内滑窗晋级；高分池逐层抬起；"类似卷积中的感受野，通过多层选优保证不漏好片"）。
  - **"1–3★ 雨露均沾"是新明确的结构性取向**：每场景/机位至少产出一张 1★+，1–3★ 以**代表性（局部相对最好且覆盖全面）**为先，艺术价值不是本轮重点。→ 模型必须同时具备**覆盖**与**局部选优**，只做全局排序无法满足。
  - **相似度阈值不是窗口**：用"特征余弦 ≥ 某阈值"的相似团替代时间窗，与 HUMAN 描述的机制不符，实测也证明阈值口径一改结论翻转（0.88 团 vs 0.97–0.98 去重给出相反结论）。**相似团只能作为诊断/加速工具，不能作为选片单位**。
  - **顺序信息必须进训练**：拍摄与选片沿时间线展开，窗口结构、连拍内位置、前后邻居内容都是判别依据的一部分（用户 2026-10-13 裁定）。但**行为规律不得规则化**（如"取末张"——统计上成立，但不构成美学评价，禁止写成规则；[SUPERVISION.md](SUPERVISION.md) §0.2 #28）。
- **预算不是固定 12.5%**：HUMAN 给的逐级比例（1★+ 40–65% / 2★+ 20–40% / ≥3★ 10–20%）是**按情况浮动的**；12.5% 只是理想锦标赛值。**12.5% 保留为历史可比点，但不再作为判据的固定点**（判据见 §4 的 AP）。
- **远期目标（不拆离）**：4–5★ 的美学判断（含组图覆盖互补、纯美学直觉），与 0–3★ 是同一能力的难度差异，不为远期设独立通道或独立验收线。
- **历史演进（留档）**：① 宪法 §0.6 单一绝对美学分；② 07-27 阶段规则 + 三级台阶（高分段强弱 → 相似组选优 → 团顶排序）；③ 09-21 三能力（局部选优 / 全局精选 / 减量不漏）；④ 09-29 第一期=前 3 星；⑤ **10-13：滑窗为一等机制、3★ 召回为产品化底线、相似团降级为代理**。旧②③里的"团内/团顶"表述均以 0.88 团口径为背景，**已按 10-13 裁定退位**。

## 4. 成功判据

- **主判据（唯一）：平均精度 AP**（2026-10-13 用户裁定，取代"达 80% 召回所需预算"）：
  - **为什么换**：原判据"R80 = 达 80% 召回所需预算"有两处致命缺陷。① **可被预算操纵**——随机选片看够约 78–80% 就能凑到 80% 召回，实测随机 R80 = 0.782（val）/0.800（test）vs 当前候选 0.770（val）/0.806（test），**无法区分随机与模型**（val 上候选甚至更低）；② **是事件构成的函数，不是模型能力的函数**——≥3★ 占比低的事件里"全留即达标"，完美打分的 R80 只有 0.084（val）/0.115（test），**低于任何可用选片器**，读数失去意义。用户指出的实质：**预算一旦浮动，只报召回就可以靠"多留一点"刷满，而保留集混进大量 1–2★ 等于没减量——准确度必须同时纳入**。
  - **AP 的定义与优点**：事件内全部照片按分数降序，逐张累加命中率后除以 ≥3★ 总数（= 各召回点精度的加权平均）。**不需预设预算**，对"多留一点"完全免疫（多留只降精度），下限天然是 ≥3★ 基准率。
  - **报告要求**：AP 必须与 ① **随机基线 AP**（≈该事件 ≥3★ 占比）、② **上限 AP = 1.0**、③ **逐事件结果** 并排；进度量用 **AP 缺口闭合率** `(AP_实测 − AP_随机)/(1 − AP_随机)`。
  - **辅助指标必须带精度，不得只报召回**：固定预算下的**精度 @12.5% / 25% / 50%**（每处并列基准率）；"达 80% 召回所需预算"**必须连同该点的保留集纯度**（纯度 = 已保留中的 ≥3★ 数 / 已保留数）一并报出。
  - 数值真源 → [KNOWLEDGE.md](KNOWLEDGE.md) §5；细则 → [METHODOLOGY.md](METHODOLOGY.md) §2。
- **上限即靶**：达标路径 = 逼近上限（AP→1.0），**不引入人类复测线**（用户 2026-10-13 裁定：标注人时成本极高，应花在提高模型效果上；下限=随机、上限=完美打分已足够定位）。**注**：以"固定预算 + 召回"表述目标时必须先核可行性（见 KNOWLEDGE §3 的所需-AUC 换算）。
- **不采用的旧判据（2026-10-13 用户裁定）**：① **废止** 0–5 星 exact/±1 目标剖面（在一把冠军位三成不稳的票数上要求复现值，与"星级只有排序意义"冲突）；② **退役**"达到人类线（0.704 冠军一致）即可用"作为验收口径——它是团内选优考卷的指标，与减量不漏不是同一件事。
- **评估口径**：容差分层报告（exact / ≤1 / ≥2 / ≥3）；tie 区（真无差异）不强迫二选一；金标准考卷（113 团）**永久不入训**；最终验收须用未参与训练与调参的完整新事件（库内数据已定型至 2026-05-10，终考只能落在未来新拍摄上）。
- **抗均值漂移**：好天气日的平庸片不应挤掉坏天气日的组内最佳——按拍摄时段分桶校验召回（宪法 §0.6/§0.7）。
- **场景覆盖**：七类典型场景（同山头不同构图、长焦梯田构成、沿山脊移动前景变化、静物连拍像素级、孤立瞬间抓拍、主体 vs 背景题材化权衡、夜景抖动）——逐类明细表见宪法 §0.5，作为产品化参考。

## 5. 原则约束（长期有效）

- 评估必须**事件级切分**，同次拍摄绝不跨 split。
- 比较只在局部可比域内发生；内容相似度是可比性主信号；禁止原始星级跨段直接组对（≥3★ 事件内全局段除外）。
- 星级标签是带噪声的软偏好：监督带可信度权重，不做"星高必胜"硬约束；
- 星级为整数，存在舍入量化噪声（照片质量可能卡在两星级之间）AI 不学它，也不许拿它当降低标准的借口，闸门只卡真实差异处（Δ≥2）。（宪法 §0.7 + plan-3-2 §6 校准注记）
- **EXIF 不必禁、当期也不入（用户 2026-10-13 裁定）**：原"EXIF 拍摄参数不进打分特征"由硬禁令改为**不再需要设禁、但当期也不引入**——理由是**焦段不同本就带来视角与景深差异，最终仍回到美学评价**，交给模型自行判断比手工喂参数更干净；反迁移实证（LOG 2026-07-19）保留为"不作为恒等特征"的依据。**涉及焦距的评价/分桶一律用 35mm 等效焦距**（focal_length × crop_factor，用户 2026-07-19 裁定——焦距本身改变评价标准）。
- **0→1 技术判别的核心 = 极相似照片对中的清晰度（用户 2026-10-13 裁定）**：**"任意两张仅像素级差异的照片，一张清晰、一张抖动，答案应当是明确的"**——这是 0→1 边界最干净、最可扩展的训练信号，按此构造对即可，不需要也不允许写成场景规则。夜景抖动是它最常见的实例（夜景 0→1 几乎全靠抖动判断），但**只作实例、不作特判**；同理适用于各类"同机位、内容近同、仅技术质量有别"的对。
- 模型输入增强必须确定性、推理期可复现；禁破坏性抹除影调；手动修图只作参照不作输入。（宪法决策 13）
- 废片闸门是模型外的独立协同算法；训练库是"删除后的幸存者"，模型不负责废片检测。（宪法决策 14）**边界澄清（2026-10-13）**："废片"指**整张删除**（模型外），与 §3 的 0→1 技术有效性判别（在幸存者内部区分可拍性）不是同一件事——后者在模型内，且是第一期主线。
- 软权重、数据驱动，不堆人工硬规则。（宪法 §0.7）
