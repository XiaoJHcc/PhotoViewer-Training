## 1. 任务核心需求（先读这个再谈技术）

- **用户与场景**：摄影爱好者（SONY A7C2），多拍选优；单次外拍 ~600 张/天，大量照片高度相似；
  历史 9418 组已全部人工 0-5 星标注（段内锦标赛产物，见 §2 的噪声定性）。
- **要替代的工作量**：人工筛一次外拍约 **5 小时**。两类最耗神：① 高度相似照片里选更好的（相对区分）；
  ② 平平无奇里挑氛围优秀的（绝对直觉）。
- **唯一目标（宪法 §0.6）**：让模型真正理解摄影美学，对任意一张照片给出反映其水准的分数。
- **★ 阶段规则（用户 2026-07-27 定）**：**不考虑任何产品化；模型准确性是唯一成功判据；
  最低成功限度 = 局部弱实现（三级台阶）**：① 高分段任意两张谁强谁弱（最低线，允许排除"重复压低"
  污染数据）→ ② 相似组内选优（选团顶）→ ③ 团顶之间排序。在达到目标前不接受逃避方案。
- **准确性标准（2026-07-28 定稿，参照系 = 金标准干净考卷，永久不入训）**：
  四层容差剖面 **exact ≥0.50 / ≤1 星 ≥0.95 / 偏 2 星 ≤0.05 / 偏 3 星 0**；
  主指标 = 稳定地带**用户尺前二命中率**，副指标 = 冠军（顶 1）决断力；tie 区（真无差异）不强迫二选一，
  模型应以"分数接近"表达不确定。**人类线（2026-08-31 同卷复测钉死，golden_retest 73 团）**：
  团内冠军一致 **0.704** / 前二 **0.926**（54 双决胜组；跨年上界 0.66-0.73/0.93 口径退役）；
  单张盲评复测 55% exact / 45% 飘1 / 0% 飘≥2——"达到人类线即判定可用"。

## 2. 数据的本质（一切设计约束的来源，压缩版）

- **星级是段内锦标赛逐轮晋级的"生存结果"**：强段内相对信号、几乎为零的跨段绝对信号；
  **只有排序、无数值意义**（禁相减/平均/回归/跨组数值比较，只可反推生成过程后按序使用）。
- **清洁度与代表身份绑定**：相似团（段内 cos≥0.88 union-find，7006 团）内落败者的低星含
  "重复压低"成分；**团顶与孤立照的原始星级干净，是绝对尺唯一合法学习源**。
- **团内旧标签约三成冠军位错误（两批金标准实测 0.732/0.658）**：失真集中在好片带（剔除琐碎后 0.61）
  与极相似带；**团内旧标签作 ground truth 已作废**，干净考卷 = `golden_exam/`（73 团）。
- **"差"的定义走绝对尺**（200 张横评：茶博是较差场次），不用组内星数值；差中选差人也不稳（判 tie）。
- **0★ 即真 0★**；**评估必须事件级切分**（泄漏 0.99 vs 藏一场 0.50，不切全是假象）；
  **EXIF 不进打分特征**（反迁移实证）。
- **事件 split（2026-08-16 重划）**：test={茶博/虎跑/良渚版本}（不动，考卷完整）、val={祥睦桥 + 西湖北外滩}、
  train=19 事件（旧 7 + 2025 批 12）；金标准集样本必须落在 test 事件。
- **M2 校准尺**：479 锚（原 205 + 2025 批扩锚 274，2026-09-19 封板）盲评 → 潜变量拟合
  `s=g(段内星)+b_seg`（全库统一的尺，干净拟合 Δ≥2 留出 0.819/外验 0.894，锚点覆盖 20 事件；
  `m2_offset_full/` 全量 + `m2_offset_full_clean/` 反泄漏训练用）；派生 derived 训练对即从此尺派生
  （18595→53420，新 13 事件全解锁）。

## 6. 对后续的建议（判据与纪律，不是计划）
