# 方法论 Methodology — 怎么研究这个任务

> **性质**：L1（agent 起草、用户确认）。本文不是结论库，也不是流程手册，而是**开展研究时必须遵守的思维方式**；它约束"怎么提出假设、怎么读数、怎么下结论、什么时候可以重开旧结论"。规范（怎么写文档）→ [DOCUMENTATION.md](DOCUMENTATION.md)；需求真源 → [HUMAN.md](HUMAN.md) / [REQUIREMENTS.md](REQUIREMENTS.md)。
> **为什么需要它**：本项目的历史失败模式不是"不够努力"，而是**读数方法本身失准**——在小样本、坏输入、无参照线的条件下判死过多个方向，把随机波动当收益、把管线缺陷当模型上限。方法论的作用是让下一位 agent 能独立判断，而不是照抄路线。
> **阅读纪律**：探索新方向（新实验、新标注、新架构）前必读本文 + [KNOWLEDGE.md](KNOWLEDGE.md)（负知识墓碑）+ [SUPERVISION.md](SUPERVISION.md) §0.2（先验登记）。

## 1. 锚定：先确定"什么算成功"，再决定"做什么"

- **任何实验都必须先写明它对应哪个目标指标**（第一期 = 0→3★ 的减量与不漏，见 [REQUIREMENTS.md](REQUIREMENTS.md) §3）。对应不上的实验，无论多有趣，都不进主线。
- **主指标只允许一个**，且必须是**端到端**的（从全部照片到最终保留集合），不能是中间环节的代理（团内冠军率、pair accuracy、某带的 exact）。代理指标可以作诊断，不能作验收。
- **目标值必须有上下限，但不需要人类复测线**（用户 2026-10-13 裁定）：下限 = 随机基线，上限 = 完美打分（计算式见 §2）。**"逼近上限"本身就是验收路径**——模型达到产品可用标准时自然可用，不必先花标注成本去建立"人类重做一遍"的分母。标注是人时成本最高的资源，应花在提高模型效果上，不花在验收账面上。
- **12.5% 预算是一个"理想锦标赛值"，不是硬性上限**：机制的真实预期是留下比例随场景浮动（HUMAN：逐级 40–65% / 20–40% / 10–20%）；预算表必须给出**曲线**（见 §2），单点数字只作历史可比点。
- **目标结构变了，历史数字必须重新读**（口径纪律见 [DOCUMENTATION.md](DOCUMENTATION.md) §5）。

## 2. 读数：三条参照线，缺一条不下结论

任何"成绩"必须同时给出三条线，否则该数字不可解释：

| 参照线 | 含义 | 缺了会怎样 |
|---|---|---|
| **随机基线** | 同一候选集下随机排序 | 会把"贴随机线"的收益当成进展（历史教训：0.1222→0.1376 被写成"真实收益"） |
| **上限** | 完美打分（AP = 1.0）；结构上限另算（每事件 `min(1, 预算/≥3★ 数)`） | 会把管线自锁当成模型上限（历史教训：结构上限 0.525 从未被计算过） |
| **缺口闭合率** | `(实测 − 随机) / (上限 − 随机)`：扣除结构因素后，模型吃掉了多少可分差距 | 只看绝对值进步，无法区分"模型变强"与"预算变宽" |

**主指标 = 平均精度 AP**（2026-10-13 用户裁定）。AP = 事件内按分数降序逐张累加命中率 ÷ ≥3★ 总数，等价于"所有召回点精度的加权平均"。

**为什么不能用"达 80% 召回所需预算"（R80）**——这是用户直接指出的漏洞，务必记住：
- **可被预算操纵**：随机选片看够约 78–80% 就能凑到 80% 召回。实测随机 R80 = 0.782（val）/0.800（test），候选 0.770（val）/0.806（test）——**两者无法区分，val 上候选甚至更低**；只要预算可浮动，模型就能靠"多留一点"刷满召回，而保留集里混进大量 1–2★ 等于没减量。
- **是事件构成的函数**：≥3★ 占比低的事件里"全留即达标"，完美打分的 R80 只有 0.084–0.115，**低于任何可用选片器**——读数反向失义。
- **AP 对这两点免疫**：不需要预设预算（多留只降精度），下限天然是正例基准率，且能暴露"降序排列本身是否合理"。

补充纪律：
- **可行性先算再定目标**：任何"预算 + 召回"判据必须先核 `预算 ≥ 80% × 该事件 ≥3★ 占比`，否则目标数学不可达（实测 6/24 事件如此）；所需排序 AUC 用 [KNOWLEDGE.md](KNOWLEDGE.md) §3 换算表读（12.5% 预算 + 80% 召回要 AUC≈0.97–0.99，属"判据选错"的信号，应调预算而非硬追 AUC）。
- **报召回必须带精度**：任何召回数字（固定预算或达 80% 所需预算）都必须并列该点的**精度/纯度**与基准率；单报召回不合法。
- **判读带范围"这条数字在噪声带内吗"**：小样本考卷（n<30 组）按 ±1 组 ≈ ±3pt 以上读，单体 LoRA 按种子带读（沿用 KNOWLEDGE §3 纪律）。区间跨零 = 不下结论。
- **区分事件宏平均与合并分母**：只在小样本上做的宏平均容易失真，两者都报。
- **必须报逐事件结果**，不能只报总计——本项目事件间方差极大（质量极差 ~2 星），总计会掩盖某个事件崩掉（本次即靠逐事件发现"候选 5/6 事件不如随机"）。

## 3. 拆解：跟着标注机制走，不要自造代理

**第一原则：选片单位必须来自 HUMAN 描述的机制，不能来自聚类阈值。** HUMAN 明确：标注是在时间线上以**滑动窗口**展开的局部比较，高分池逐层抬举（"类似卷积中的感受野，通过多层选优"）。因此

- **可比域 = 时间序上的局部窗口**（段内近邻 + 逐层抬举得到的相邻高分池），**不是**"特征余弦 ≥ 某阈值"的相似团——后者是 agent 自造代理，阈值一改结论全变（2026-10-13 实测：0.88 团口径与 0.97–0.98 去重口径给出相反结论）。
- **顺序信息必须进训练**（用户 2026-10-13 裁定）：拍摄与选片都是沿时间线展开的，窗口结构、"这张在连拍里的位置""当时前后还有什么"本身就是判别依据的一部分。
- **但不得把行为规律规则化**：如"末张更优"（团顶为本团末张 0.30–0.34 vs 随机 0.20–0.22）在统计上成立，然而"取最后一张"根本不构成美学评价，是奇技淫巧——**禁止写成规则或先验通道**，只允许作为模型可自行学习的输入结构存在（[SUPERVISION.md](SUPERVISION.md) §0.2 #28）。

**第二原则：按机制环节拆解差距。** 目标指标掉下来时，先回答"差距在哪一环消失"（0→1 技术闸门 / 雷同取舍 / 局部选优 / 覆盖），每环独立测量再决定投入。**优先级 = 减量幅度 × 当前完成度 × 证据可获得性**。按当前实测：0→1 技术闸门减量最大（40–65%）、完成度最低（AUC 0.57）、信号最全 → 第一期主线。

**反模式**：① 自造代理当目标（团、对、accuracy），代理一旦不具备产品用途就会模糊目标——项目历史上长期优化"团内冠军位"（一个既不是产品动作、也非 HUMAN 机制的量），而忽略了"团本身选得对不对"；② 在未确定瓶颈环节前，用"再标一批""再上数据量""再调权重"覆盖整体差距（[KNOWLEDGE.md](KNOWLEDGE.md) §6 已三次证死）。

## 4. 先验 → 假说（本项目的研究循环）

HUMAN 的要求是"从标注数据中洞察出可能的先验信息……将理由挖掘出来"。落实为固定流程：

1. **来源分层**：HUMAN（用户手写真源）> 标注中用户即兴给出的判断（SUPERVISION 各集"中途启发"）> 实测规律（agent 从数据测出）。**三者的效力不同**：HUMAN 是约束，实测规律只是观察，**观察不得升格为规则**（见 §3 的"末张"反例）。
2. **登记**：[SUPERVISION.md](SUPERVISION.md) §0.2 登记，注明类型、来源与验证状态。
3. **转成假说必须写成三项**：
   - **预测**：可测量的方向 + 量级（"把 X 加入后，指标 Y 应从 a 升到 b"），不能只写"应该有用"；
   - **最小证伪实验**：用**现有数据**能跑的最小实验（优先离线复算，不训练）；
   - **判死条件**：什么结果算证伪（区间跨零 / 只在该考卷有效 / 只在单一事件有效）。
4. **一次只动一个前提**。若实验同时改了输入版本、标签来源与模型结构，结论不可归因（route-review §5 的"未隔离混杂因素"即此）。
5. **执行后**：结论进 [KNOWLEDGE.md](KNOWLEDGE.md)（带数字与口径），先验状态回流 §0.2，**无论正负**——负结论与正结论同等价值，都必须写明。
6. **标注是最后手段**：发起新标注前先回答"现有标签能否回答这个问题"（对号入座用 [SUPERVISION.md](SUPERVISION.md) §8 可用信息总账）；新标注的收益必须写成"预计把主指标提升 X"，否则不发起。

**示例（本次审计产出，含一次被"机制合理性"而非"数字"拦下的假说）**：先验 = HUMAN"以几乎相同的机位多次拍摄……取到最佳位置" → 预测 = 相似团内团顶更可能是本团最后一张（实测 0.30–0.34 vs 随机 0.20–0.22，方向成立） → 最小实验 = 作为软特征并入选片器（+0.7~1.4pt，方向正但幅度在噪声带内） → **判死**：用户 2026-10-13 以**"这不是一次美学评价"**直接否掉了它——即使数字为正也不采纳。**这一例的教益**：假说除了"数字是否成立"，还要过**"它是否属于我们要解决的任务"**这一关；一个统计上为真的行为相关信号，可能根本不在目标语义内（[SUPERVISION.md](SUPERVISION.md) §0.2 #28）。

## 5. 结论的效力期限：重开条件

每条判死的方向都要写明它依赖的前提，前提变了就有权重开：

- **输入版本**（`render518` → `display-plane-v3`；未来若再改渲染/解码路径，全部历史结论需带条件复审）；
- **标签版本**（锦标赛原星 / golden 盲选 / 多数决 / 未来重标）；
- **考卷版本与规模**（113 团考卷之前的小样本结论一律弱证据）；
- **指标口径**（改动主指标后，旧成绩不能直接比较）。

**重开不是无条件重复**：重开时必须写明"新前提改变了什么、这次能证伪什么"（[DOCUMENTATION.md](DOCUMENTATION.md) §3 推翻规程）。

## 6. 与产品的关系（不要越界）

- 训练侧**不得为训练目的改变产品用户可见行为**（AGENTS"对产品的契约"）。
- 但**产品侧的正确性会影响训练侧**（2026-09-26 输入修复即例）：训练输入链路必须与产品同一像素路径，任何"为了快"的旁路都要视为潜在错误源，先验证再使用。
- 产品化门槛 ≠ 训练验收：第一期达成（0→3★ 可用）才谈产品化，在此之前**不以产品方案代替模型质量验收**（REQUIREMENTS §3 阶段规则）。

## 7. 交接：让下一位 agent 能独立判断，而不是照抄路线

- 交接的最小充分集 = **目标仪表盘**（离目标多远）+ **负知识（带重开条件）** + **当前假说台账**（在试什么、预测是什么、何时判死）。路线本身可以推翻，判据与证据不可以。
- 禁止在文档里写"下一步照做 X"而不写"为什么是 X、什么情况下该改主意"。
- agent 的产出应以**证据**为单位，而不是以**文档字数**为单位：一次会话的价值 = 消除了多少不确定性。
