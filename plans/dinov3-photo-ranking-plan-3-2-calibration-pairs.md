## 5. 初期想法（**均未锁定**，开工时按真实分布重定）

> 自 plan-3-1 §6.1 迁入（2026-07-05）。

### 5.1 M2 评分偏移法

- **粒度**：偏移按**拍摄段**给（不按日历日）；段切分用 plan-3-0 §1 决策 2 的"时间间隔 + 相似度"那套，与可比域同源。
- **估偏移的办法**：每段抽几张代表，连同**精修精品锚点**一起丢进一个**绝对池**做一次跨组评级（小型 meta-锦标赛）；某段代表在绝对池里的级别 − 它原本的段内级别 = 该段偏移。精修片天然钉住高端。
- **刻度**：偏移后用**连续刻度、不 clamp 回 0-5**（好天 5★+2=7、坏天 0★−2=−2 是对的，表达更宽的真实绝对范围）。
- **怎么喂训练**：段内对继续用**原始段内星级、高权**（可靠地基）；跨段对用**偏移后绝对星级派生、低权**（粗信号）。
- **诚实边界**：偏移是手工注入的绝对判断、±2 很粗，质量上限卡在这——它是**锚不是真值**。M2 GATE 必须验：重复评级是否自洽、跨天"同绝对级"能否对齐；不行就退回纯相对、绝对留 v2。
- **备选：可学习段偏置**（承 plan-3-0 §1 决策 3d，待 plan-3-1 §1.5 绝对性探针 + §1.4 段数核算后定配比）：偏移不逐段手标，改为训练时每段一个可学习自由参数 b_seg（score = f(x) + b_seg，推理期丢弃）——段均值被 b_seg 吸收，f(x) 被迫只用视觉特征解释跨段差异，恰好对准挑战 3；人工只需精修锚点 + 少量跨段对**钉住尺度**，并验证学出的 b_seg 与人工感受自洽（好天气段偏置应系统性偏高）。段数达几百级、逐段手标不可行时，这是主路线而非备选。

### 5.2 M3 配对域按标注机制分层（2026-07-19 补录，未锁定）

- **0-3★ 局部段**：段内滑窗 + 相似度加权 + 条件保留 + 大星级差降权（既定路线，见 §2 决策清单 5-8）。
- **≥3★ 全局段**：允许事件内跨段组对（plan-3-0 §0.3 两段标注机制 + 决策 2 例外）——该段标签当年就是事件内全局比出的；组对量与权重（相对局部段应否低权）待 M2 锚定结论与 audit 分布定。
- 探针已实证两段结构差异：≥3★ 事件内可学性 79-84% vs 局部段 60-62%（见 EXECUTION-LOG 2026-07-19）；全局段的跨事件迁移为零，其绝对尺度同样依赖 M2 锚定。

### 6.1 M2 跨段绝对校准

**决策 1（3a/3d 配比）：3a 人工偏移为主、3d 学习偏置为辅。**

- §1.5 判词：冻结特征 + 线性/非线性读出，跨事件绝对尺全灭（藏一场考·场内 S 0.50 / L 0.57、MLP 复核 S 0.499；Spearman≈0）——3c 特征泛化腿弱，3d 赖以成立的前提"f(x) 能解释跨段差异"当前不存在；
- 标签侧方差分解（≥3★ band，**等级近似等距的粗略体量、非精确份额**，v1.7 原则下只作参考）：段级偏移（事件+段两级）最多吸收 ~49% 绝对尺方差，剩 ~51% 段内每张的真实差异只能由 f(x) 承担——3a 管粗尺、3d 退居辅助（训练时吸收段均值残差 + 自洽校验）；
- **段间(34%) > 事件间(15%) → 偏移做在段级、不做事件级**（宪法 §0.7"可比性按场景实际变化"实测支持）。

**决策 2（正式段表）：gap>10min → 120 段，定稿。**

- 边界已验证（跨段 cos P99.9=0.725）；段大小 1-585 张、中位 28。
- **段 = 偏移粒度单位，不是代表单位**（段内中位 9 个相似团、段代表居中合格仅 47%——时间段代表已被验证否决，LOG 07-19）。
- 29 个 <8 张小段单列：无锦标赛形状，其封顶星数是尺寸 artifact、不作跨段信号。

**决策 3（绝对池构成：相似团代表制）。** 代表单位 = 相似团（段内 cos≥0.88 union-find，2569 团；0.88 依据 audit §3"几乎必然同场景"）。

- **核心代表**：85 个 16+ 大团的团顶（全部锦标赛形完整）——21 个已在 abs_set 免标，**新标 64 个**；
- **孤立照**（979 张单张团）：**≥3★ 的 66 张全入**（宪法场景 5 命门；14 已在 abs_set，新标 52）；0-2★ 按事件分层抽 ~30 张作低端锚定（其跨段约束**低权**——长距离低端对比在标注历史上很少真实发生，宪法 §0.3 v1.7）；
- **无锦标赛形状段**：<8 张段（29）与 ≤2★ 封顶段（34）并集（执行时按 `clusters.csv` 去重生成清单，~50-60 段）的段顶照直接进池人工定位；
- **高端钉住**：is_retouched 150 张不参与评级，直接作顶层参照（3b）；
- **校验集**：abs_set 200 张——141 张自身是团顶可双职当代表，59 张非团顶仅作校验点；
- **评级工作流**：复用 abs_set 流程（复制抹星 → 全量程盲评 → 读回 → key 回库）；新标合计 ~200 张（64+52+30+~55），半天~一天；
- **自由校验信号**：≥32 张段（58 段）的"封顶星数"在同一场内构成真实发生过的跨段排序（出过 4★+ 的段 > 止步 3★ 的段）——作偏移拟合的独立校验约束（宪法决策 2 例外条款的派生形态）。

**决策 4（校准方法：排序进、排序出）。** 用户 07-19 裁定：**标注只能给排序、给不了绝对数值**（abs_set 的 0-5 也只是有序等级、级距无意义）；库内一切星级同理（宪法 §0.3 v1.7 原则）。~~"绝对级 − 段内名义级"的减法~~因预设两尺数值可比而作废。

- **标注形态 = 有序等级（允许并列）**：锚点池评级只要"水平相近同级、高等级恒优于低等级"——跨段约束从等级差派生（高一级 > 低一级；同级 = 并列、不产生约束），不赋予级距任何数值含义。
- **拟合 = 潜变量排序模型（Bradley-Terry / Thurstone 风格）**：潜分 `s(x) = g(段内局部序) + b_seg`。`g` 单调（自动保住段内老排序不破），`b_seg` 逐段一个；参数 ~130 个 vs 数千约束对，良态。拟合目标 = 加权满足约束集——① **锚点池跨段/跨事件排序对**（主约束，高权）；② **大段封顶约束**（58 段，场内"出过 4★+ 段 > 止步 3★ 段"，中权）；③ **精修顶端约束**（被精修者应落在尺的顶部区域，弱权）；④ 段内老排序由 `g` 单调性自动保持。无锚段 = 向同事件有锚段的 `b` 收缩（先验；`b` 是模型自身潜尺度上的量，做收缩合法，与星级数值无关）。
- **输出**：连续潜分——**其数值仍无绝对意义、只用其序**（派生跨段对、定召回线）；"不 clamp"（§5.1）的含义随之改为"不外推压平、允许多段共演的宽序"。
- **诚实边界（回应"可能对也可能不对"）**：段级偏移假设 = "段有一个整体水准"——对滑窗+筛选的标注生成方式**可能**成立，对段内内容突变**可能**不成立 → 不由假设担保、由 GATE 检验；GATE 不过的升级路径 = 偏移粒度下沉到相似团（`b_cluster`，clusters.csv 已备好），再不过 → 退回纯相对保底（plan-3-0 §0.6）。
- **M2 GATE 落实为三条（全部排序口径）**：
  1. **重复评级对级一致率**：池内暗放 10-15% 重复件（盲评者不知情复评）——同一对照片两次评级的先后关系一致比例 ≥90%（并列的处理规则首跑定，阈值为首跑草案）；
  2. **留出锚点回测**：拟合时随机留 20% 锚点不用——其**预测序 vs 实评序**的对级一致率（阈值首跑校准）；
  3. **封顶排序约束**：58 个大段场内约束的满足率（本就是排序约束，作 sanity，预期应高）。

### 6.2 M3 训练对生成

- **决策 5（窗口 + 权重映射）**：window=20；相似度→权重 = cos≥0.973→1.0 / 0.918→0.8 / 0.786→0.5 / 0.540→0.3 / <0.73→0（audit §9 冻结）。段内滑窗对 = **高权**（可靠地基，原始段内星级）。
- **决策 6（tie / 条件保留）**：τ_cv=0.078（保守·主口径）/ 0.126（激进·对照）；cos≥0.98 且 CV 距离 < τ_cv → 判 tie 丢弃不监督。
- **决策 7（大星级差降权）**：草案 Δ=3 → ×0.5、Δ≥4 → ×0.25（宪法决策 4"跨 3 星以上多为跨场景、降权"；生效前按配对量分布复核）。
- **决策 8（跨段对）**：
  - **≥3★ 全局段**：事件内跨段组对（决策 2 例外）——原始星级直接组对、**中权**（该比较当年真实发生；探针实证事件内可学性 79-84%）；
  - **其余跨段对**：只允许由**偏移后潜分派生**、**低权 ×0.2**（草案）；跨事件派生对同低权、且仅在**潜分排序显著分隔**时生成（阈值按锚点对差分布定——对齐 M2 粗尺精度，避免把偏移误差当信号）；
  - 绝对禁止：原始星级跨段/跨事件直接组对（宪法 §0.7）。
- **决策 9（split）**：按事件整体切（决策 11）——test = 2-3 事件（**含金标准集所在段**、优先覆盖七类场景），val = 1-2 事件，其余 train；执行时按金标准集攒集进度定名单。**锚点反泄漏条款**：b_seg 拟合与盲评锚点是传导式的——M4 评估时须对 test 事件**重拟合 b_seg（剔除 test 事件全部锚点与 abs_set 照片）**，否则绝对涌现测量被污染（决策 11"金标准段必入 test"的同款逻辑）。
- **决策 10（候选组格式）**：以 cluster 为原子单位组织（cluster_id 承 `cluster_mine`），每照片存 `{fingerprint, event, seg_id, cluster_id, cluster_size, rating_raw, b_seg, abs_score, is_retouched, cv_tie_dist, weight_meta}`；pairwise/listwise 两者可派生（决策 12），换损失不重做数据工程。

### 6.3 风险与触发器

- **M5 概率上调为"大概率"**（§1.5 证据：细尺半边 ~51% 当前无任何已测手段能交付）——M4 绝对涌现不足时，首选 M5 加大偏移监督 + targeted 跨段标注，再回决策 8 升级梯（梯 4 LoRA 兜底）；失败分诊查 plan-3-3 §4 锁定映射。
- **一切尺皆序（v1.7）**：abs_set 新尺、库内老尺、M2 产出潜分——三者都只可比序、不可比值；跨尺禁止数值运算，只允许排序对照。M2 潜分的刻度由锚定池的排序关系定义，不对应任何"星"。
- abs_set 只覆盖 ≥3★ band：方差分解等标签侧结论仅对顶部 band 成立，全量程结论待 3a 池标完复核。
