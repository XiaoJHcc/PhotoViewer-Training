# 自动选片路线审查与下一轮实验建议

> 2026-09-21。依据本次用户目标、宪法、交接文档、执行台账、当前训练/评估代码和已有分数复算。
> 本文区分已验证事实与建议；未启动新训练，未修改原始标签、模型、split 或宪法中的架构约束。
> 原始复核产物：`audit/out/route_review_20260921.py` 与 `route_review_20260921.json`（本地覆盖式产物，不入库；JSON 含输入 SHA256）。

## 1. 判断与需求重新对齐

方向没有整体走偏：事件级留出、承认锦标赛标签的局限、补盲评、保留全画面视觉与原分辨率 CV，都是正确投入。
但后半程的推进重心逐渐偏向“小考卷冠军率”和“继续攒团内干净对”，**最薄弱的全局精选能力没有得到同等直接的监督与验收**。

本次目标应被直接写成三项可测能力：

1. **局部选优**：相似组中保留一张或数张真正值得留的照片；允许多个等价最佳，保留可解释的差异。
2. **全局精选**：组顶与孤立照片放在一起，能找出跨组仍然出色的照片；“差组中最好”不自动等于“全局好”。
3. **减量且不漏佳作**：给定人工能看的张数，最大限度保住值得留的作品，并压低重复占位。模型质量必须在这个预算下兑现。

“单一分数/单头”属于实现约束，不是这三项用户价值本身。旧宪法 §0.6 明确禁止双头；本次建议重新审视该约束，但尚未把双头写成已采纳方案。局部排序与全局分数可以共享视觉理解，也可以分开优化；不能先验要求所有梯度在一个读出头上兼容。

历史“每段配额以保住坏天气组”和本次“挑全局最好的组顶”是两个不同选择目标。离线报告应分别给出作品质量与场景覆盖，不能用配额带来的覆盖冒充审美增益。12.5% 是既有工作量预算，可继续作为曲线上的重点位置；不应硬编码每个组都晋级同样比例。

## 2. 同卷复算：局部模型比旧比较略强，但“前二平人类”不足以验收

本次直接读取已有 ens、fw2ep2 与混合分数，复算 94 个判定组；人机同分母取 `golden_retest/retest_report.md` 列出的 54 个双决胜组。复测人类结果沿用已读回报告，本次没有重新标注照片。

| 范围与指标 | ens | 混合 fw2 | 人类复测 |
|---|---:|---:|---:|
| 原完整考卷：冠军命中，94 组 | 44/94 = 46.8% | 严格去重后 46/94 = 48.9% | 不适用：人类不是这 94 组 |
| 同卷：冠军命中，54 组 | 26/54 = 48.1% | 31/54 = 57.4% | 38/54 = 70.4% |
| 同卷：模型所选落在人类前二，54 组 | 50/54 = 92.6% | 50/54 = 92.6% | 50/54 = 92.6% |
| 同卷好片团：冠军命中，13 组 | 6/13 = 46.2% | 7/13 = 53.8% | 历史同口径 7/13 = 53.8% |
| 同卷好片团：所选落在人类前二，13 组 | 12/13 = 92.3% | 12/13 = 92.3% | 历史同口径 12/13 = 92.3% |

这既纠正了旧报告把 94 组模型和 54 组人类直接相减的问题，也说明**好片 13 组上冠军的点估计已经相同，不能再用不同分母宣称这一子域有确定缺口**。不过 n=13 太小，也不能反向宣称已经具备人类泛化水平。

更关键的是“前二”定义：`golden_exam_eval.py` 测的是**模型选一张，该张是否属于人类前二（包含次优并列）**，不是“模型保留两张，人类冠军是否被保住”。

- 94 组中有 **56 组仅两张**；加上次优并列，共 **61/94 组随便选任何成员都满足前二**。
- 同一口径的组内均匀随机基线已是 **82.4%**；混合为 **92.6%**。确有提升，但不能把 92.6% 直接解读为广泛的高准确率。
- 真正“每组保留模型前两张，冠军仍在”的召回为 **82/94 = 87.2%**；同卷好片 13 组为 **10/13 = 76.9%**。这只是补充诊断，仍须结合保留张数预算与组大小评估。
- 现有考卷剔除了 19 个 tie/tie0 团，没有测“应当并留”“全组不值得留”和“不确定应复核”；不能仅凭该考卷验证这些能力。

严格冻结协议发现旧混合 CSV 对同一指纹有重复行；旧读取方式取最后一行。去重并保留组上下文后，混合完整考卷冠军为 **46/94=0.489**，模型保留两张含冠军 **82/94=0.872**，所选在人类前二 **87/94=0.926**；因此旧报告的 48/94 不再作为当前基线。混合相对 ens 的严格完整考卷改善为 2 组（改善 8、退步 6）。按组配对 bootstrap 10,000 次，差值区间仍跨零，不能把 94 组当成 94 个独立拍摄事件。

当前考卷只覆盖 3 个事件，良渚一场占 47/94 组；反复据此选模型、epoch、规则后，它已承担开发集功能。没有直接入梯度不等于仍是未触碰终考。现有考卷继续永久不入训、用于回归；下一次泛化声明必须另有未用于决策的新事件终考。

## 3. 多数决值得用，但历史“噪声降至 5%”推断不成立

`44/46 有 ≥2/3 多数冠军` 测的是**多数意见的形成率**，没有独立真值时不能推出 44 个多数冠军都正确，更不能推出错误率只有 4.3%。三轮还包含一轮旧锦标赛标签，与两轮盲选并非同协议、独立同分布。

`golden_mv_eval.py` 的“人类单轮 vs 多数决 = 0.848”又把该人类单轮本身放进多数决，属于参与构造参考答案后的自一致率，不能当独立人类上限与模型相减。Copeland 对级多数序与“多数轮冠军相同”也不是同一统计量，44 与 46 的两个口径不能混用。

正确用途：保留每次偏好与 tie 状态，估计稳定性；对争议样本追加独立复测。比较模型与人时，让被评估的人类轮次不参与构造参考答案，模型与人使用完全相同的组、参考答案、可选集合。当前是个人选片助手，优先同一用户跨会话复测；不同人的投票会改变偏好目标，不能自动当作更干净的个人尺。

因此，“模型仍有能力缺口”有证据，但“缺口只能靠多数决训练解决”没有被证明。

## 4. 全局精选仍是主缺口，现有考卷也需要分清能说明什么

当前 ens 在现有 oracle 团顶候选上，≥4★ 召回为 **11/71 = 15.5%**：

| 事件 | 候选照片 | 旧标签 ≥4★ | 命中 |
|---|---:|---:|---:|
| 茶博 | 70 | 7 | 0 |
| 虎跑 | 90 | 17 | 1 |
| 良渚版本 | 458 | 47 | 10 |

这些仍是旧标签下的代理指标；弱势非常值得重视，但不能视为直接的“人类全局审美准确率”。需注意：

1. `tops_exam_eval.py` 用旧星级确定候选团顶；不是模型自行选出的代表。8443 个“团顶∪孤立照”实际来自 7006 团，包含 **1437 个并列团顶额外成员**，不是每团去重后恰好一张的结果。
2. `top-N` 的 N 来自该事件真实 ≥4★ 数量，是 oracle 配额，不是部署时预先可知的工作量预算。它适合作代理，不是端到端减量证明。
3. 事件内域 A 将所有异星团顶配对；团顶身份只减轻重复压低，不能修复 0–3★ 跨拍摄段的可比性。跨两级的序差也不会自动消除这种上下文偏差。
4. 当前名为“跨事件”的 abs test 924 对里，**357 对仍在同事件、567 对跨事件，总共只有 68 张独立照片**。需按两端事件关系拆报，不能把 924 当独立样本数。
5. 召回采用合并分子/分母，随机基线却平均每事件比例，权重不一致。本次同权重随机基线 **12.3%**，非原报告 13.1%；不改变“全局精选弱”的定性。
6. 域 A 的逆序计数把模型等分当“不逆序”；故常数模型能得到 100% 的所谓对级一致。新评估须显式区分正确、错误、模型 tie（如 tie 给 0.5 或单列），并补常数/随机对照。此缺陷不等于当前已存模型分数就是常数。

M2 潜分也只能作有条件的教师：`s=g(旧星级)+b_seg` 对同段旧顺序强制保序，不能修复其中的冠军错误；按照片留出锚点且段仍有训练锚点，测到的是该校准模型的插值，并不证明视觉模型对新事件具有同等能力。

历史台阶① **0.766（n=1422）** 是旧 derived 考卷成绩。本次当前 `pairs_test.csv` 的 derived 仅剩 dstar=4/5，**dstar=2 为零对**；不能把 0.766 当作当前重建考卷已复现成绩。训练对、考卷、标签和归一化参数必须独立版本化，禁止覆盖考卷后沿用旧数比较。

`band_hybrid.py` 又只为已有考卷成员生成按组切换的分数；分数在考卷集合上各自标准化。组内排序时这种尺度处理不影响单专家排序，但**它没有验证专家分与基础分能跨组比较**，不能直接拿混合输出证明全局尺度已统一。

## 5. 训练里存在尚未隔离的混杂因素

本次当前 CSV 复核：

- 常规训练对 **207039**（window 72702 / global 80914 / derived 53423），干净对 **1026**，涉及 **769 张独立照片、19 个事件**。
- 1026 对中 **666 对同时出现在旧监督**；其中 **162 对方向相反**。`m5_lora.py` 把 golden 追加到旧对列表，没有替换冲突来源。这不是对标签谁对谁错的自动裁定，而是需要显式处理的监督矛盾。
- golden 仅占均匀抽样对数 **0.493%**。默认每批 16 对，近似只有 **7.6% 批次含任一 golden 对**。`×20` 只改损失权重，并不让干净对出现 20 倍；损失又按每批权重和归一化，因此也不能从全库权重总和直接推断梯度份额。
- fw2 报告显示 `w_abs=0.0`：这轮并未直接训练 abs 盲评绝对对，而是学习 M2 派生尺。它不构成对“更好直接全局监督”的否定。

这些足以说明“继续重标一批然后原配方 ×20”并非信息量最高的下一步。也还不足以断言它们就是全部失败根因；必须用受控实验验证。

历史失败应保留，但结论收窄到**该输入、该标签、该模型、该优化与该考卷条件下没有稳定增益**：

- S/L、518/1024、LoRA、全量微调失败，不等于所有模型结构和先验都已穷尽。
- 一个 CLIP+LAION 美学头不匹配个人标签，不等于所有审美预训练无效；它仍是当前系综成员，说明存在互补信号。
- patch 单 query 池化失败，不等于显式两图交互、差异区域建模已经被试过。
- 单体局部改善同时全局退步，是需检验的任务冲突/数据混合迹象，不能证明“学局部必然损伤全局”。

不建议原样重跑旧实验赌种子；新实验必须改变已识别的前提，并声明能否证伪什么。

## 6. 建议的新验收协议

所有项先离线实现，不以产品集成替代模型质量验收。星级继续只作有上下文的顺序，禁止将 0–5 直接当等距审美分做回归或收益计算。

| 能力 | 主指标 | 必须伴随报告 |
|---|---|---|
| 局部选优 | 人工认可最佳集合的命中；模型保留 1/2/自适应 k 张时的最佳保留率 | 候选组大小、平均保留张数、tie、逐事件、随机基线、稳定/不稳定组 |
| 全局精选 | 固定预算下人类精品集合召回、明确必留照片漏选率 | 孤立照/组顶分别报、好组/差组、同题材难例、跨事件/事件内分别报 |
| 减量 | 保留 5%/12.5%/20%/30% 时的精品召回曲线 | 模型真实分组与选代表后的全链路；重复占位、场景覆盖、原始照片数 |
| 达到人类 | 同事件、同候选、同预算、同独立参考上的人机差值 | 事先确定允许差距；配对区间、逐事件结果；不能用“不显著”代替等效证明 |

将“人工认可最佳集合”“精品/必留”直接作为新标注目标，比从星级跳档间接猜测损失更贴近任务。差一档可是真实边界，也可能不稳定；两档以上也可能受上下文污染，不能只靠序差自动断言确信度。

新终考建议先从 **5–8 个从未用于调参的完整事件**做试点，覆盖目标题材、质量与近重复密度；最终样本量依据试点的事件间方差与非劣界限决定，这个事件数本身不保证统计充分。预先冻结模型选择规则，考后不再据终考改阈值；再改就留下一批事件复验。

## 7. 推进顺序与停止条件

### A. 先修证据链和训练供料，再跑一次有解释力的消融

1. 冻结现有 ens / fw2 / 混合、输入分数、考卷、标签及哈希；旧考卷作为开发回归集，保留其永久不入训约束。
2. 统一人机分母；补随机、常数、ties、严格跨事件拆分；将旧标签代理指标和人工直接真值分开。终考不能使用真实星级挑候选。
3. 干净标签和旧监督按无向照片对建立来源记录。对可信的新标签有明确优先级；争议冲突标注出来复测，禁止悄悄双向重复监督。单次新盲评不自动比旧标签可靠。
4. 在当前架构做小型受控消融：原配方 → 只处理来源冲突 → 再做按事件/组/监督源的分层 batch。干净对在批内有固定份额，来源损失分别归一化；总步数、见图预算与干净对曝光次数明确记录。先做工程冒烟，胜出候选再至少 3 种子，所有选择用开发验证集。
5. 不只看局部上升：同时看固定的局部与全局干净验证集。若只学到重复曝光导致的训练提升，或全局继续恶化，就不重复加倍 golden 权重。

优先原因：不需要再耗一轮大量人工标注，就能检验现有“标签质量唯一瓶颈”的解释是否成立。

### B. 把下一批标注的重点移向全局精品

建议首轮将约 **一半标注预算给全局/组间，三成给局部困难组，两成给独立复测与真 tie**；这是可调整的启动配比，不是已验证最优比例。

- 全局从各事件的多样代表、孤立照、模型可能漏掉的照片中抽样；不能只取模型高分或旧星级团顶，否则会看不到漏选。保留随机探索份额与抽样概率。
- 同题材、相近质量的组顶互比，专门标“局部赢家但整体平庸”与“跨组仍出色”的差异；同时有跨事件锚点连接比较图。
- 分批展示少量照片，可用最佳/最差/可并留/全部不值得留的选择；不要迫使用户用满 0–5 等宽桶。跨批使用重复锚点检测会话漂移。
- 避免强迫数千张全库重标。先做数百张规模的试点，检查新增直接偏好是否提高全局验证，再扩量。
- 局部继续采集构图、瞬间、主体与背景取舍、技术细节的真实分歧；不要把“旧星≤2”整体解释成技术判别，把“旧星≥4”整体解释成纯美学。
- 记录可选的简短理由/关注区域供错误分类与训练研究；不要求分项审美分数，也不把理由变成未经核验的新真值。

### C. 允许用不同学习通道表达局部与全局能力

若 A 排除简单监督冲突后仍出现明显拉扯，建议解除“必须单头”的先验限制，做两臂对照：

- **全局通道**：学习单图可跨组比较的个人审美排序，直接使用新增跨组盲评；M2 derived 降为弱辅助教师，不能把伪标签规模当人工信号规模。
- **局部通道**：相似组内对图像/patch/CV 作比较，选择 1 或数张；可先冻结全局基础分，只学习局部比较残差。局部相对值只用于选代表，入全局精选仍使用经验证的全局分，避免带条件拼接的尺度污染。
- **共享约束**：共用视觉骨干或冻结特征；用开发验证控制容量与计算预算。必要时对已验证的全局比较作保序蒸馏，观察能否减少遗忘，而不是默认单体改进必然破坏全局。
- 若两通道无收益，保留单通道；这是一项针对“局部/全局冲突”的可证伪实验，不是架构升级承诺。

局部 true tie 与模型不知道不是一回事：前者可并留或交去重，后者需要多保留候选。分数差、专家分歧要在留出标注上校准风险，不能直接当可靠置信度。

### D. 用小型挑战集重新检验外部审美先验

在 A/B 的新协议可用后，再比较现有 DINO、一个更贴审美任务的视觉先验，以及一个能同时看两张图的多模态比较器；先冻结模型做探针或小头个人偏好适配，再决定是否微调。候选的具体模型、资源、许可证和可用性需单独核实，本次未做外部模型检索，故不指定未经验证的“最佳新模型”。

题材先验要用同内容难例检查；比较器随机交换左右位置、只根据画面回答，不给旧标签/文件名提示。外部模型不能给自己的评估集造真值，不能以解释文字好听代替排名正确。

只有候选在**相同干净考卷、同工作量预算下，改善全局精选且不明显伤局部**，才值得投入新的特征提取或长训练。否则停该候选，继续数据与目标诊断，而非重开无边界调参。
