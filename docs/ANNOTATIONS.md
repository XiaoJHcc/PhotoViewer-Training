## 2. abs_set（200 张跨事件横评，2026-07-19 标注）

- **目的**：造一把跨场的排序尺，检验冻结特征能否直接读出绝对好坏（§1.5 绝对性探针）；后作 M2 校验集。
- **协议**（用户原话）：
  - 下达："只选 3 星以上的（0-2 星很多只是因为重复而被标低）；复制 JPG/HEIF 到一个文件夹、抹掉旧星级，我按往常锦标赛习惯从 3 往上标。"（会话 486a1cab，07-19）
  - 实际执行改全量程："我已经尽可能将水平相近的照片标为同一星级，并确保任意高星级通常都比任意低星级好。"（07-25）
  - **重要定性**："我依然只能排序，不能打出绝对星级……老星级和新星级不可能存在任何数值上的对照可比性，你能拿到的只有排序。""我按照不同的量程打分。"（07-25）——**abs_set 是排序尺不是绝对星等标尺，且内部不同段量程不统一**。
- **规模与构成**：200 张（160 HIF + 40 JPG，中性名 P0001–P0200）；分层 = 11 事件（每事件 ≥8）× 73/120 段 × 旧 3/4/5★=108/53/39；读回新分布 0★48/1★49/2★50/3★33/4★14/5★6。
- **位置**：`D:\PhotoDB\dataset\abs_set\` + `abs_set_key.csv`（new_name↔指纹/事件/旧星/段）+ `abs_set_ratings.tsv`。
- **状态**：已读回（200/200，字节级无冲突）；141 张本身是团顶（可双职当 M2 代表），59 张非团顶仅作校验点。
- **脚本**：`audit/abs_set_sampler.py`（seed 42）、`probes/abs_probe.py`。
- **出处**：LOG 07-19（§1.5 三条）。
