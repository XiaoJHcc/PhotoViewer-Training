## 1. 任务目的（需求锚点，先读这个再谈技术）

- **用户与场景**：摄影爱好者（SONY A7C2），多拍选优工作流；单次外拍 ~600 张/天，同地点多角度多焦距反复尝试，大量照片高度相似；历史积累上万张，已全部人工 0-5 星标注。
- **要替代的工作量**：人工筛一次外拍约 **5 小时**。两类最耗神的工作：① 在一大堆高度相似的照片里选更好的那张（相对区分）；② 在一大堆平平无奇的照片里挑出氛围优秀的（绝对美学直觉，更难）。
- **产品门槛**：把需要人工细看的量压到 **Top 12.5%（≥3★）**，**≥3★ 召回 ≥80%**。商业成功 = 5 小时 → 半小时人机协作，不追求全自动精确打分。
- **唯一目标（宪法 §0.6）**：让模型真正理解摄影美学，对任意一张照片给出反映其水准的分数——**包括没有相似可比的孤立照片**。同一个分数既要在相似组里分得开、也要对孤立照片站得住，不拆两个头。
- **审美优先级**：构图 > 内容（可遇不可求的瞬间）> 光影/氛围/色彩。影调末位不是不重要，是**可后期修复**；构图/内容不可救。
- **七类验收场景**（任何中间产物/最终模型都必须能应对，详见 plan-3-0 §0.5）：同山头不同焦距构图取舍 / 长焦梯田抽象构成 / 沿山脊前景变化 / 静物连拍像素级差异 / 孤立瞬间氛围抓拍 / 主体 vs 背景的题材化权衡 / 夜景抖动分区判断。
- **评估两条线**（宪法决策 10 + §0.6 v1.9）：≥3★ 召回 @ Top 12.5%（产品门槛）；0-5 准确性**容差三层** exact / ±1 / ≥2 硬错误（人工飘 1 星常态、飘 2 星几乎不可能；≥2 须区分"重复压低污染"样本单析），**目标剖面 exact ≥50% / 飘1 ≤45% / 飘2 ≤5% / ≥3 为 0%**。
- **保底交付形态**（结构性安全垫）：段内 ranking + 每段 Top 12.5% 配额 + 去重压低 + 废片闸门——不依赖跨段绝对分即逼近产品门槛；跨段绝对分负责上行空间。**注意：保底线的"段内 ranking"在新拍场上同样需要跨场迁移能力（见 §3 第 6 条，这是当前卡点的严重性所在）。**

## 2. 数据的本质（一切设计约束的来源）

- **星级是段内锦标赛逐轮 Top ~50% 晋级的"生存结果"**：0-3★ 偏局部（临近滑窗选优），3-5★ 偏全局（事件内总体最优）。它给出**强的段内相对信号、几乎为零的跨段绝对信号**——好天气的 3★ 与坏天气的 3★ 水准差很多但标签一样。
- **星级只有排序、无数值意义（宪法 v1.7）**：禁止相减/平均/回归，只可反推生成过程后按序使用。级距不等距、不同段标准不同（用户按时间序、有限上下文滑窗打分；长距离对比靠 ≥3★ 筛选压缩照片量才得以发生 → 跨段约束顶部可靠、低端弱）。
- **清洁度与代表身份绑定（v1.8）**：相似团内落败者的低星含"重复压低"成分（输给近重复兄弟 ≠ 绝对差）；**团顶与孤立照的原始星级未受污染，是绝对尺唯一合法学习源**；非团顶只在段内滑窗对使用（决策 1 真实差异条件保留 + 决策 5 等价判 tie）。
- **团内精细判别 = 美学任务（v1.9）**：连拍间构图/瞬间取舍是挑战 1 核心，不是"去重杂务"；仅"真无差异"才判 tie。
- **整数舍入是量化噪声**：AI 不应学它（Δ=1 约束降权），评估也不拿它当松口借口——**闸门只卡真实差异处**（重复件跳档、Δ≥2 回测）。
- **0★ 即真 0★**（两盘全部已评，无"未评"）；**评估必须事件级切分**（泄漏 0.99 vs 藏一场 0.50，不切全是假象）；**EXIF 不进打分特征**（反迁移实证，仅作分桶元数据）。

## 3. 结论链（每一步为何走到下一步）

1. **标签可信性验证通过**（文件夹层级 vs XMP 5170 组零不一致；0★ 语义用户终裁回填清零）。
2. **M1 探针三连否定**：冻结 DINOv3 特征的"谁更好"信号跨段零迁移——排除单批同质（H3）、排除池化丢信息（H2）、排除 backbone 大小（梯 2 ViT-L 同灭、仅事件内泄漏上界 +10pt）；事件内可学 79-90%（含泄漏）。→ **特征非决定性瓶颈、标签结构才是 → M2 锚定是唯一主路；backbone 定格 ViT-S（ViT-L 不死锁）**。
3. **§1.5 绝对性探针**（200 张 ≥3★ 抹星盲评重标，跨场一致尺）：藏一场考场内 S 0.50 / L 0.57（MLP 复核同灭）、Ridge Spearman≈0、泄漏口径 0.99、跨事件粗放置 0.71-0.76。→ **绝对尺只能由监督引入；M5 大概率触发**；新尺方差分解：事件间 14.7% / 事件内段间 34.1% / 段内张间 51.2%（段偏移最多补一半，且必须做在段级）。
4. **代表有效性验证否决"时间段代表"**（段内中位 9 团、段代表居中合格仅 47%）→ **相似团机制**（段内 cos≥0.88 union-find，2569 团；团代表天然成立）；abs_set 与团顶交集审计：141 张双职代表、59 张仅校验点。
5. **M2 排序制校准（GATE 通过）**：约 400 张盲评排序（abs_set 200 + 标注池 205）→ 潜变量拟合 `s = g(段内星) + b_seg`（排序进、排序出）→ **全库第一把统一的尺**：留出回测 Δ≥2 0.857-0.897、Δ≥3 0.91-0.95、重复件跳档 0/22。附带发现：g(2★)=g(3★)（中间层无绝对信息，硬边界 0→1 与 4→5）；事件偏移地图与体感一致（绍兴顶、茶博底）。
6. **M3 训练对（GATE PASS）**：三类各守纪律——window（段内滑窗高权，全体照片）/ global（≥3★ 团顶事件内中权）/ derived（干净潜分派生低权）；split 事件整场（test=茶博/虎跑/良渚、val=祥睦桥，用户定案；**金标准集须落 test**）；锚点反泄漏干净重拟合。
7. **M4 首考（段内 GATE 不达标）**：能背不能带（train 对级 0.977 vs test ~0.52，管线无 bug——与 M1 探针证据链完全一致）；消融：CV 全图统计无跨场信号、**EXIF 反迁移（弃用）**、**ViT-L 唯一弱脉搏（test top-1 0.333 vs chance 0.155、derived 0.615、茶博绝对序 -0.55→+0.27）**。→ 按失败映射（plan-3-3 §4 全场景平庸→特征可分性）**回决策 8 升级梯；升级梯成为保底+上行两线的共同前提**。
8. **梯 3（ViT-L/16@1024）**：【管线运行中，结果待填——见 §5】

## 4. 方向调整记录（哪些判断被推翻过、为什么）

| 原方案/说法 | 调整为 | 原因 |
|---|---|---|
| 108 对跨段配对标注（§1.5 初案） | 重标制（200 张抹星盲评） | 用户：0-2★ 多为重复淘汰非绝对差；重标直接产出绝对尺 |
| "每段抽 1-2 张代表" | 相似团代表制 | 数据否决：时间段是"一串活动"非"一堆相似照"，段代表居中合格仅 47% |
| "绝对级 − 名义级"算偏移 | 排序进、排序出的潜变量拟合 | 用户：星级只有排序、新老尺无数值可比性（宪法 v1.7） |
| GATE 重复一致率阈值 0.90 | 跳档口径 + Δ≥2 闸门 | 用户：整数舍入是量化噪声，不学、也不许当松口借口 |
| "下游别学中间层" | 清洁度精确化（v1.8） | 脏的不是中间层，是落败者的压低星；团顶干净 |
| "团内排序是去重杂务非美学" | 团内精细判别=美学任务（v1.9） | 用户纠正：连拍取舍是挑战 1 核心；0-3★ 难分=高相似判别难度假说 |
| EXIF 进打分特征 | 弃用（仅分桶元数据） | M4 消融实证反迁移（学场次↔器材习惯，跨场反噬） |
| backbone 定格 ViT-S（M1） | 维持，但 M4 后升级梯成两线前提 | M4 段内 GATE 不达标；ViT-L 有弱脉搏，LoRA（梯4）是决战 |
