## 1. 批次层级标签与 0★ 规则（跨批通用）

- **事件边界是可比性硬边界**：不同事件文件夹的照片不可直接做星级比对；同一事件文件夹内部可看作一组。拍摄段切分（10 分钟间隔）在事件内部进行。
- **F: 批文件夹层级 = 星级层**：无后缀机型文件夹 = 0★（仅 HIF/JPG）、`-OK` = 1-2★、`ARW3*` = 3★+（混机型筛选、标准基本一致）；层级与 XMP 星级交叉验证 5170 组零不一致。
- **0★ 即真 0★**：两个照片盘（`F:\照片2026-P2`、`D:\PhotoDB`）全部评过，XMP 0 或字段缺失一律是真 0★，不存在"未评"。
- **2025 批口径**：只有排除、没有未评——读不到星级的就是被淘汰的 0★（NO 文件夹 7034 张落 0★）。
- Stack（曝光包围连拍）与延时摄影不参与评级、不入库；`OUT-JPG*` 是 ACR 精修导出件，不入库、只作 `is_retouched` 回溯来源。
- **总纲**（一切标注语义的地基，宪法 v1.7 来源）：所有星级只代表排序、无数值意义；排序都产自临近滑窗；长距离对比靠 ≥3★ 筛选压缩照片量后才真实发生；不同段标准不同确实存在。
- 出处：[../data/BATCHES.md](../data/BATCHES.md) 分组规则节；LOG 07-19 / 08-05。

## 2. abs_set（200 张跨事件横评，2026-07-19 标注）

- **目的**：造一把跨场的排序尺，检验冻结特征能否直接读出跨场好坏（§1.5 绝对性探针）；后作 M2 校验集与绝对尺试点。
- **协议（实际执行）**：抽样限旧标 ≥3★（0-2★ 很多只是重复淘汰而非绝对差，掺入会稀释信号）；照片复制为抹星中性名副本（P0001–P0200）后盲评。原设计承接锦标赛习惯"从 3 往上标"，实际执行为**全量程 0-5**：水平相近打同星、任意高星恒优于低星。
- **定性（重要）**：这把尺**只有排序意义**——用户明确它不是绝对星等标尺，且各段打分所用量程不同。因此 abs_set 内部、以及它与库内老星级之间都只可比序、不可比数值；任何文档不得称其为"绝对标尺"。
- **规模与构成**：200 张（160 HIF + 40 JPG）；分层 = 11 事件（每事件 ≥8）× 73/120 段 × 旧 3/4/5★ = 108/53/39；读回新分布 0★48/1★49/2★50/3★33/4★14/5★6。
- **位置**：`D:\PhotoDB\dataset\abs_set\` + `abs_set_key.csv`（中性名↔指纹/事件/旧星/段）+ `abs_set_ratings.tsv`。
- **状态**：已读回（200/200）；其中 141 张本身是团顶（可双职当 M2 代表），59 张非团顶仅作校验点。
- **脚本**：`audit/abs_set_sampler.py`（seed 42）、`probes/abs_probe.py`。
- **出处**：LOG 07-19（§1.5 三条）；定性表述经会话考古（09-27）核对。

- **协议（实际执行）**：整团照片放入一个文件夹，用户按日常选片习惯直接标星——**星级只表组内排序，最高星即团顶（冠军），并列即 tie**。用户同时给出的解读先验：与旧标签不一致大多是首位/次位交换；"差中选差"没有稳定性；极相似对中一张给了高星、另一张就会被重复压低。
- **与后续批次的边界**：批1 **没有**星差置信度约定（置信度编码自批2 起）；"全 0 = tie0（整组不可判）"的专门语义也首见于批2。

- **状态**：已读回；噪声实测 0.732（见 [KNOWLEDGE.md](KNOWLEDGE.md) §1.1）。

## 6. golden 批2（golden_star2，100 团 328 张，2026-07-28 导出 / 07-30 标注）

- **目的**：扩考卷（加密极相似带）+ 产出团内干净训练对。
- **协议（实际执行）**：同批1（组内标星 = 组内排序），并新增**星差携带置信度**：星差越大越确定（0:3 很确定、0:1 不太确定）；0:0 = 无法排序，对应三种情形——两张同样烂没有细挑的必要 / 真的一模一样 / 没有可比性（如一横一竖且该场景无横竖偏好）；3:3 = 同好（很可能是本该分属两个团的团顶）。
- **用户给出的判别依据分层**：高置信判别主要来自清晰度（现有 CV 可判）与构图水平度（0.5° 级，当时 CV 未覆盖）；路人位置/姿态这类低置信细节，模型判错可不追究，但应体现在置信度表达上。
- **规模与构成**：exam 25 团（极相似带 cos≥0.96 优先）+ train 75 团（潜分带配额 顶35/中25/底15）；极相似带占 36/100（批1 为 14/48，有意加密）；读回 win 76 / tie 9 / tie0 15。
- **产出**：干净训练对 **325 对**（按确信度加权：gap1 ×0.5 = 186 / gap2 ×1.0 = 99 / gap≥3 ×1.5 = 40；同星剔 130）。
- **位置**：`D:\PhotoDB\dataset\golden_star2\`（`H###_X` 命名）。
- **脚本**：`audit/golden_batch2_sampler.py`、`golden_pair_gen.py`。
